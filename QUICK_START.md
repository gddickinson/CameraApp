# Quick AR Usage Guide

## Getting Started

After building and running the app, you'll see three modes:

### 📷 Camera Mode
Standard photo capture with all camera controls.

### 🎯 AR Object Placement Mode
1. Hold device upright and move slowly
2. Blue transparent planes will appear on surfaces
3. Select an object from the bottom toolbar (cube, sphere, pyramid, cylinder, torus)
4. Tap on a blue plane to place the object
5. **Long press** on any object to remove it
6. Tap the reset button (↻) to start over

**Tips:**
- Move slowly for better surface detection
- Use textured surfaces (wooden tables work great)
- Good lighting is essential
- Objects have physics and will interact with surfaces

### 🖼 AR Image Tracking Mode

#### Step 1: Generate Markers
1. Tap "Generate Markers" button
2. You'll see 3 colored markers (Blue #1, Green #2, Red #3)
3. Save each marker to Photos
4. **Print them out** or display on another screen/tablet

**Important:** Markers need to be printed or displayed at a reasonable size (at least 3-4 inches wide) for best tracking.

#### Step 2: Use the Markers
1. Close the marker generator
2. Point your camera at a printed/displayed marker
3. AR content will appear on the marker:
   - **Marker 1** (Blue): Spinning cube
   - **Marker 2** (Green): Pyramid
   - **Marker 3** (Red): Three bouncing spheres

**Tips:**
- Print markers clearly (laser printer or high-quality inkjet)
- Avoid glossy paper that creates reflections
- Hold marker flat and steady
- Ensure good, even lighting
- You can track up to 3 markers simultaneously!

## Test Scenarios

1. Launch app → Select "AR Mode"
2. Point at a table

5. Tap to place sphere

3. Save all three markers

## Troubleshooting

**No planes detected?**
- Move device slower
- Ensure good lighting
- Try a textured surface (wood, fabric)
- Point camera at surface at an angle

**Image tracking not working?**
- Print markers larger (try 6-8 inches)
- Use non-glossy paper
- Ensure marker is well-lit
- Hold marker flat and steady

**Objects falling through surfaces?**
- Wait for surface to stabilize (becomes solid blue)
- Place objects near the center of detected planes
- Avoid edges of detected surfaces

**App crashes or AR not available?**
- Ensure device is iPhone 6s or later
- Check iOS version is 13.0+
- Some features require newer devices

## Device Requirements

- **Camera Mode**: Any iPhone with camera
- **AR Object Placement**: iPhone 6s or later
- **AR Image Tracking**: iPhone 6s or later

Best experience: iPhone X or later
